# agent-ledger

[日本語](README.md) | [English](README.en.md)

AIエージェントに長く仕事を任せていると、セッションが切れるたびに「いま何をしていたか」が消えます。状態をまとめた文書を作っても、更新し忘れて実態とずれます。agent-ledgerは、記録を**追記専用のログ1本**（`log.jsonl`）に集める小さなCLI `j` です。「いまの状態」は保存せず、毎回ログから導出します。

- 書き込み口は `j` だけです。採番・時刻・ファイルロックが揃うので、複数のセッションが同時に書いても壊れません。
- 記録するのは出来事だけです。決定・金・出荷・問い・回答・数値予測・仕組みの変更の7種類です。
- `j now` が、未回答の問い・直近の決定・今月の収支・いま作業中のセッションをログから組み立てます。新しいセッションはこれを読んで再開します。

## 動作要件

- Linux または macOS（`fcntl.flock` を使います。Windowsは非対応）
- Python 3.8以降（標準ライブラリだけで動きます）

## 使い方

`j` をPATHの通った場所に置くか、そのまま実行します。帳面は環境変数 `J_ROOT` のディレクトリ（未指定なら現在のディレクトリ）の `log.jsonl` です。

```sh
export J_ROOT=/path/to/myproject

j decision -p game "依頼主「タイトルはAで行く」。タイトルをAに決定"
j ask -p game "体験版の配布先はitch.ioでよいか"
j answer --re <ask-id> "itch.ioでいい"
j money -1500 "サーバー代" --ref invoice.pdf
j ship -p game "体験版を公開" --channel itch --ref https://example.itch.io/demo
j promise -p game "公開30日でDL 100件以上"
j sys "ビルド手順をMakefileに移した"

j now            # 再入ビュー
j now -p game    # 事業を絞る（未分類・全体収支・全占有は常に表示）
j money          # 今月の収支表（--month 2026-08 で別の月）
j ships          # 出荷一覧
```

`j now` の出力例:

```
== NOW 2026-10-06 23:01 ==

■ 未回答の問い (1件)
  [<ask-id>] (game) 体験版の配布先はitch.ioでよいか

■ 直近の決定・回答
  2026-10-06 12:00:00 decision (game) 依頼主「タイトルはAで行く」。タイトルをAに決定

■ 今月の金 (2026-10): -1,500円 (1件)

■ 事業 (projects/*.md)
  game         最終更新 2026-10-06 / 最終出荷 2026-10-06

■ 占有中のセッション (1件)
  game ← codex:0199... (22:54 から)
```

### 複数セッションの同居

- `j claim <事業>` で、その事業を作業中だと宣言します。`j release` で解放します。紳士協定なので、ほかのセッションの書き込みは止めません。4時間たつと自動で表示から消えます。
- 誰が書いたかは `who` 欄に入ります。決め方は、`J_WHO` → Cursorの会話ID → CodexのスレッドID → tmuxのセッション名 → `manual` の順です。`j who` で確認できます。

### 事業の一覧（任意）

`J_ROOT/projects/<事業>.md` を置くと、`j now` に事業ごとの最終更新日と最終出荷日が並びます。中身は自由です。事業の入口メモとして1枚ずつ置く想定です。

### 金額の単位

金額は符号付き整数で、収入が正です。表示の単位は環境変数 `J_UNIT` で変えられます（既定は「円」）。

## エージェントへの指示例

`AGENTS.md` や `CLAUDE.md` に、たとえば次のように書きます。

```markdown
- 記録の正本は log.jsonl、書込みは j のみ。決定・金・出荷・問い・回答・数値予測・仕組みの変更を発生時に1行記録する。
- 依頼主の言葉は逐語で残す。
- 状態やまとめの文書は新設せず、現在は j now / j money / j ships から導出する。
- 作業開始時や記憶が切れたときは、まず j now を読んで再開する。
- 事業に触る前に j claim <事業>、終えたら j release。
```

## 設計上の決まり

- `log.jsonl` は追記専用です。行を書き換えたり消したりしません。誤記は新しい行で訂正します。
- `j <種別> --help` は使い方を表示するだけで、記帳しません。
- `--` より後ろは文字どおりの本文として扱います（例: `j sys -- --help -3000`）。
- 本文が空の記帳と、`--re` のない `answer` は拒否します。
